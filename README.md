# Hospital Management System - SQL Project
This project simulates a basic *Hospital Management System* using SQL. It involves the design and implementation of tables for doctors, patients, departments, appointments, and billing.

### Features:
- Track patient and doctor details
- Manage appointments and their statuses
- Maintain billing and payment records
- Analyze data using JOINs, GROUP BY, and conditions

### Technologies:
- SQL
- MySQL / PostgreSQL (any RDBMS)

### Key Queries Demonstrated:
- Join multiple tables for insights
- Aggregate revenue and appointment stats
- Filter unpaid bills and generate reports

### Skills Showcased:
- Relational schema design
- Data insertion and normalization
- Complex query writing
